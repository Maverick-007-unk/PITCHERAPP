Which navigation layout fits PITCHER best?

Pick the overall shell for the web platform

A — Icon Sidebar

Collapsed icon rail on the left. Hover or click to expand labels. Maximizes content area. Common in tools like Linear, Vercel, Figma.

B — Full Sidebar

Always-visible sidebar with labels, sections, and org switcher. Standard SaaS pattern (Notion, Slack, HubSpot). Great for complex navigation.

C — Top Navigation

Horizontal top nav bar with tabs for each section. Dashboard fills the full width below. Cleaner feel, works well for fewer main sections.
